# Freedom Music · Windows

Flutter-клиент для Windows. Корневой обзор монорепозитория: [../../README.md](../../README.md).

Готовые сборки: [релизы](https://github.com/TheSadFreedom/FreedomMusic/releases).

```bash
flutter pub get
flutter run -d windows
flutter build windows --release
```

Положите MP3 в папку `music` рядом с приложением и отсканируйте её в Настройках.
